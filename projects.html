Pillpadi

Software project

An AI-powered pill identifier and dosage reminder app for elderly Nigerians. It has voice support in Yoruba, Hausa and Igbo. It uses on-device OCR and cloud AI vision to identify medication, and it sends automatic SMS alerts to caregivers when a dose is missed.

Smart social media autopost system

SIWES project · Docker and n8n

A smart social media autopost system built with Docker and n8n during my SIWES. It schedules and sends posts without doing the same steps by hand each time.

Smart AI medication system

Final year project · Hardware and software

My final year project. The hardware uses AI to recognise pills. The user can set alarms for medications. A mobile app connects caregivers so they can follow up on doses.
